# Соцтакси Водитель

Android-приложение водителя социального такси (Flutter). Показывает заказы своей
машины на сегодня и завтра, ведёт статусы поездок, получает изменения от
диспетчера в реальном времени и передаёт диспетчеру положение машины.

## Что умеет

- Вход по логину и паролю, которые выдаёт диспетчер (сессия сохраняется).
- Список поездок «Сегодня / Завтра»: время подачи, «быть к», клиент, мобильность,
  сопровождающий, откуда → куда, статус. Машина может везти нескольких клиентов
  сразу — все активные поездки выделены, сверху строка «Сейчас в машине: N».
- Экран поездки: звонок клиенту и доп. контакту, диагноз, заметки, комментарий
  диспетчера, кнопки «Маршрут» (навигатор телефона или Яндекс Карты), одна большая
  кнопка следующего шага: «Выехал к клиенту» → «Я на месте» → «Клиент в машине» →
  «Доставил». Отдельно — «Клиент не вышел / отмена» с причиной и «Вернуть
  предыдущий статус».
- Новые и изменённые диспетчером заказы помечаются «НОВЫЙ / ИЗМЕНЁН / ОТМЕНЁН»
  и требуют нажать «Принял» (или открыть заказ). Диспетчер видит, принял ли водитель.
  О снятых с машины заказах приходит отдельное сообщение.
- Обновления: Realtime + опрос каждые 45 секунд + при возврате в приложение.
  Об изменениях — уведомление со звуком.
- «На линии»: пока переключатель включён, координаты машины уходят диспетчеру
  (не чаще раза в 10 с, не реже раза в 30 с). На Android это работает и при
  свёрнутом приложении — через постоянное уведомление «вы на линии».
- Плохая связь: последний список хранится на телефоне и показывается с пометкой
  «Нет связи, данные от ЧЧ:ММ».

## Запуск для разработки

Нужен запущенный локальный Supabase из корня проекта (`supabase start`) и
демо-данные (`node web/scripts/seed.mjs --demo`, логины и пароль — в этом же файле).

```bash
flutter run                      # Android-эмулятор, сервер — 10.0.2.2:56421
flutter run -d chrome            # в браузере, сервер — 127.0.0.1:56421
```

Для телефона в той же сети или для боевого сервера укажите адрес и ключ:

```bash
cp env.example.json env.json     # вписать SUPABASE_URL и SUPABASE_ANON_KEY
flutter run --dart-define-from-file=env.json
```

## Сборка APK

```bash
flutter build apk --release --target-platform android-arm,android-arm64 --dart-define-from-file=env.json
# файл: build/app/outputs/flutter-apk/app-release.apk
../deploy/deploy.sh   # выложит APK на https://staxi.apsoftgroup.ru/app/soctaxi-driver.apk
```

- `env.json` — адрес сервера и `ANON_KEY` (образец — `env.example.json`). Строки `DEMO_…` включают
  кнопку «Демо-режим» на экране входа (отдельная демо-база с вымышленными заказами).
- В release-сборке разрешён только HTTPS (обычный HTTP открыт лишь в debug —
  для локального сервера).
- Подпись: ключ `android/app/soctaxi-release.jks`, пароль — в `android/key.properties`.
  Оба файла не хранятся в git. **Сохраните их копию в надёжном месте:** без этого
  ключа новую версию нельзя будет установить поверх старой — водителям придётся
  удалять приложение и ставить заново.
- Перед выпуском новой версии поднимите `version` в `pubspec.yaml` (например `1.0.1+2`).

## Устройство кода

```
lib/
  main.dart               запуск, тема, выбор экрана (вход / заказы / сообщения)
  config.dart             адрес и ключ сервера (dart-define), интервалы
  models.dart             Trip, Client, Vehicle, статусы и подписи
  app_state.dart          загрузка, Realtime, опрос, сравнение списков, кэш, RPC
  location.dart           «На линии»: поток координат → driver_report_location
  notify.dart             локальные уведомления
  launch.dart             звонок и маршрут
  screens/
    login_screen.dart     вход
    home_screen.dart      список заказов, «На линии», баннеры изменений
    trip_screen.dart      карточка поездки и смена статусов
    status_screens.dart   «нет машины», «нет связи», загрузка
  widgets/trip_card.dart  карточка поездки в списке
```

Водитель ничего не редактирует напрямую: статусы и подтверждения идут через
функции базы `driver_set_status`, `driver_ack`, `driver_report_location`,
`driver_set_off_duty` (см. `supabase/migrations`).

## Замечания

- `flutter analyze` в этой папке падает из-за кириллицы в пути (ошибка самого
  инструмента Flutter). Используйте `dart analyze` — он работает.
- Push-уведомлений (FCM) нет: если приложение полностью закрыто, водитель узнает
  об изменениях только открыв его. Пока водитель «на линии», приложение живёт в
  фоне и уведомляет само.
